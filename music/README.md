# Biblioteca de música de fundo

Coloque aqui faixas instrumentais **royalty-free** (`.mp3`, `.wav`, `.m4a` ou `.ogg`).
A cada vídeo do pipeline Christian, uma faixa é escolhida aleatoriamente e tocada
em volume baixo (`MUSIC_VOLUME`, padrão 0.06) por baixo da narração, com fade-in/out.

Sem arquivos aqui, o vídeo é gerado normalmente, sem música.

Garanta que a licença de cada faixa permite uso comercial/YouTube (ex.: CC0,
ou licença própria de uma biblioteca como Epidemic Sound/Artlist se você tiver
assinatura). Se a licença exigir atribuição, anote o autor/fonte em algum lugar
(ex.: nome do arquivo) para não esquecer na descrição do vídeo.
